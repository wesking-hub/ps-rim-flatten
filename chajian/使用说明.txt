========================================================================
          文字边缘修复 (rim-flatten v9) Photoshop CEP 插件
========================================================================

【功能简介】
本插件采用 v9 联合 Y/Cr/Cb 异方性局部平面回归算法，用于消除 AI 生图、
扫描文档中文字/图标周围的振铃波纹与色块内部凹凸斑块：
- Y / Cr / Cb 三通道联合估计：同步抹平明度凹凸与色度团块噪声；
- 连续结构场保边：保护白字笔画、细小图标与抗锯齿边缘，无黑线串色；
- 无需手动调参：自动适配浅底深字、深底浅字及各色笔刷底块；
- 默认生成仅含选区像素的「rim-flatten 修复层」并自动绑定选区蒙版，
  原图层不动，蚂蚁线选区完整保留。

------------------------------------------------------------------------
【运行环境要求】
- Adobe Photoshop CC 2018 ~ 2026（Windows 10 / Windows 11）
- 本机已安装 Python 3（支持 py -3.11 / python / python3）及以下库：
  pip install numpy opencv-python numba

------------------------------------------------------------------------
【快速安装】
1. 完全退出 Adobe Photoshop。
2. 双击运行本目录中的「一键安装.bat」（会自动配置 CEP 调试模式并
   将 com.local.rimflatten.cep 复制到 %APPDATA%\Adobe\CEP\extensions\）。
3. 重新启动 Photoshop。
4. 在顶部菜单打开插件：
   【窗口】 -> 【扩展功能(旧版)】 -> 【文字边缘修复 rim-flatten】
   （PS 2024~2026 中可能位于【窗口】 -> 【扩展】或【增效工具】）

------------------------------------------------------------------------
【使用教程】
1. 用选框、套索等工具框住需要修复的文字/色块区域（四周尽量留出约 30px
   背景以便局部平面回归取样）。
2. 点击面板上的「开始处理选区」。
3. 处理完成后会在当前图层上方生成「rim-flatten 修复层」（若勾选
   “直接合并至当前图层”则直接覆盖选区并可 Ctrl+Z 撤销）。

------------------------------------------------------------------------
【卸载方法】
双击运行本目录中的「一键卸载.bat」即可删除已安装的扩展目录。
